# Ozon Order Copier v9.21

## Исправления

- Для плиток завершённых заказов без ссылки и номера добавлен «переход по клику»:
  скрипт кликает плитку, дожидается перехода на `orderdetails`, забирает номер
  заказа из URL и возвращается назад. После этого заказ выгружается полностью:
  номер, названия товаров, количество, адрес ПВЗ, статус оплаты.
- Номер ищется из всех `state-*` элементов страницы: если плитку удалось
  сопоставить по дате и сумме, клик не требуется.
- Если ни один способ не сработал, остаётся частичная выгрузка (дата, статус,
  цены, фото), а диагностика показывает, что именно не получилось.

## Примечание

- Во время экспорта возможны короткие переходы на страницу заказа и обратно
  (до 5 плиток за один запуск). Это цена за полные данные по завершённым заказам.
