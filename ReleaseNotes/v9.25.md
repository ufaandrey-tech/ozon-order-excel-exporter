# Ozon Order Copier v9.25

## Исправления

- Номер «безымянной» плитки теперь ищется в HTML списка заказов:
  скрипт подтягивает SSR-страницу «Актуальные» и «Завершённые» и находит
  карточку по совпадению ID фотографий товаров (fallback — дата получения).
  Кликов и переходов нет.
- Добавлен мост в страничный мир (`src/core/bridge.js`) через внедрение
  скрипта с nonce и `postMessage`: он читает Vue/React-инстансы и Nuxt-пейлоад,
  если они доступны. Используется, если поиск по HTML не дал результата.
- В диагностике: `DOM.listPageMatch` / `DOM.listPageMiss`, `DOM.bridge*`.

## Ограничения

- HTML списка может не содержать номера у таких плиток — тогда остаётся
  частичная выгрузка (дата, статус, цены, фото).
