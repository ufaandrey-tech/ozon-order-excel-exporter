# Ozon Order Copier v9.36

## Диагностика (для перехода к структурному правилу)

- `DOM.pictureContext` снимается всегда при поиске номера для плитки
  (фрагмент HTML вокруг фото, цепочка предков, `data-*`).
- `DOM.pictureNumbers` — какой номер получился для каждого фото.
- `DOM.pictureRejected` — номер найден, но `orderdetails` не подтвердил фото.

## Детерминизм

- Голосование удалено. Номер принимается только если все фото дают один номер
  И он подтверждён точной сверкой фото в `orderdetails`.
