# Ozon Order Copier v9.40

## Исправления и скорость

- Заказ из плитки ищется и на следующих страницах архива
  (`?selectedTab=archive&page=2..4`). Раньше проверялась только первая
  страница, а у активного покупателя 10 ноября могло быть уже на второй.
- Перебор всех номеров подряд убран: проверяются только заказы, в карточке
  которых есть дата получения из плитки. Если таких кандидатов нет — перебор
  не выполняется (быстро).
- Точная сверка фото через `orderdetails` осталась обязательной: номер
  присваивается только при совпадении фотографий.
- Диагностика: `DOM.archiveNumbers` (сколько номеров/кандидатов),
  `DOM.archivePages` (остановка пагинации), `DOM.detailsScanSkipped`.
