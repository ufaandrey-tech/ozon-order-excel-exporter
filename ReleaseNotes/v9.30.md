# Ozon Order Copier v9.30

## Исправления

- Добавлен перебор номеров из HTML списков: до 20 номеров проверяются через
  `orderdetails`, и выбирается заказ, где совпало нужное число фото плитки.
  Это работает, даже если карточка в списке разнесена по разным веткам DOM
  (фото и ссылка не рядом).
- Для перебора используется лёгкая выборка фото (`fetchOrderPictures`) —
  без диагностических снимков, чтобы отчёт не раздувался и не тормозил.
- Диагностика: `DOM.detailsScanMatch` / `DOM.detailsScan` (сколько номеров
  проверено).
