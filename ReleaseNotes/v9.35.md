# Ozon Order Copier v9.35

## Детерминизм

- Убрано «голосование» и любые догадки. Номер заказа для плитки присваивается
  только если:
  1. каждое найденное фото даёт **один и тот же** номер (по структуре DOM или
     по ближайшей ссылке перед фото в порядке документа);
  2. этот номер **подтверждён** точной проверкой: в `orderdetails` совпало
     нужное число фото плитки (≥2 для многотоварной плитки).
- Если условия не выполнены — номер не присваивается: строка остаётся
  частичной (дата, статус, цены, фото). Неверных номеров быть не может.
- Диагностика: `DOM.pictureNumbers` (номер по каждому фото),
  `DOM.pictureRejected` (номер не подтверждён), `DOM.pictureContext`
  (структура HTML вокруг фото — для перехода к чисто структурному правилу).
