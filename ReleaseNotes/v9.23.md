# Ozon Order Copier v9.23

## Исправления

- Ozon собран на Vue (`vendor-vue.js`), а не на React — поэтому поиск
  `__reactFiber$` ничего не находил. Добавлен поиск номера заказа в Vue-инстансах:
  `__vueParentComponent` / `__vnode` / `__vue__` (props, ctx, setupState, data).
- Поддерживается прямое поле с номером (`orderNumber`, `orderId`, `number`,
  `postingNumber`) — номер извлекается без кликов и переходов.
- Диагностика частичной плитки теперь сообщает, есть ли Vue-инстанс и на каком
  уровне DOM он найден.

## Примечание

- Userscript работает в режиме `@grant none`, поэтому Vue/React-свойства
  DOM-узлов доступны.
