# Ozon Order Copier v9.29

## Исправления

- Сопоставление плитки с заказом теперь идёт «от фото»: для каждой
  фотографии плитки находится ближайший предок ровно с одной ссылкой заказа,
  номера суммируются как голоса, и берётся номер с большинством голосов.
  Раньше шли «от ссылки к контейнеру», и фото в соседней ветке не попадали
  в проверку — заказ не находился, хотя все 4 фото в HTML архива были.
- Поиск изображений расширен на `srcset` / `data-src` / `<source>`.
- Диагностика: `DOM.pictureVotes` (номер → сколько фото рядом).
