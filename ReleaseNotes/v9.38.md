# Ozon Order Copier v9.38

## Исправления

- Одно и то же фото товара может встречаться несколько раз: в промо-плитке
  сверху (без ссылок) и в настоящей карточке заказа ниже. Раньше
  `querySelector` брал только первое вхождение (плитку) и номер не находил.
- Теперь проверяются **все** вхождения фото; номер берётся только из того,
  где рядом ровно одна ссылка заказа. Если у фото несколько разных номеров —
  результат считается неоднозначным и не используется.
- Диагностика `DOM.pictureNumbers` показывает по каждому фото: `occurrences`,
  найденные `candidates` и итоговый `orderNumber`.
- Обязательная проверка фото через `orderdetails` сохранена: без совпадения
  номер не присваивается.
