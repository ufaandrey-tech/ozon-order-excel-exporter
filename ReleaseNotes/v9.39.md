# Ozon Order Copier v9.39

## Исправления

- Если по HTML списка номер найти не удалось (фото есть только в промо-плитке),
  выполняется **точная сверка** по данным заказов: номера из списков
  проверяются через `orderdetails`, и номер принимается только при точном
  совпадении фотографий (≥2 для многотоварной плитки).
- Это не догадка и не голосование: без совпадения фото номер не присваивается.
- Номера с датой получения в карточке проверяются первыми.
- Диагностика: `DOM.detailsScan` (сколько проверено, у скольких есть фото,
  топ совпадений) и `DOM.detailsScanMatch` (точное совпадение).
