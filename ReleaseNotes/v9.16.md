> **3 августа 2026**

## 🔧 Что исправлено/улучшено

- **Чистое ядро парсинга `parseOrdersV2JSON`** — JSON orderlist разбирается чистой функцией без обращения к DOM, что позволило покрыть парсинг автотестами на реальных схемах Ozon (Фаза A0).
- **Единый безопасный доступ `getPath`** — доступ по путям вида `a.b.c` и `a.b[0].c` с fallback вместо разрозненных `try/catch` (Фаза A1).
- **Утилита `formatAmount`** — единый источник форматирования сумм (Фаза A1.5).
- **Каскады путей-кандидатов** для `pickupPoint` / `cardDeliveryDate` / `fallbackAmount` / `paymentStatus` — устойчивость к изменению схемы Ozon: новые пути добавляются перед старыми, ничего не ломается (Фазы A2/D).
- **Исправлена потеря копеек в суммах** — `parseFloat` + запятая (Фаза A2).
- **Дата доставки из orderdetails** поднимается на уровень заказа (Фаза A3).
- **Три состояния диагностики OK / FAIL / N/A** + чистая `createParseResult` + параметризованный `buildDiagnosticsMarkdown(env, deduped, state)` — тестируемый отчёт (Фазы B1–B3).
- **`jsonPayment` заполняется и в JSON-first** — статус «Оплачен» больше не теряется (Фаза C).
- **`extractAddressFromDoc`** — тестируемое извлечение адреса ПВЗ из страницы orderdetails (Фаза E5).
- **Диагностика pickupPoint N/A→FAIL** — если поле помечено «не применимо» (N/A), а адрес из orderdetails так и не восстановился (fetch упал после retry) — это реальная потеря адреса, и в diff-отчёте теперь показывается **❌ FAIL**, а не «🟡 N/A» (W-1).
- **Тесты на реальных схемах Ozon** (старая с `title`/`cellList` и новая без них), фикстуры анонимизированы (Фаза E).

## 🔬 Ручная проверка на странице Ozon

> ⚠️ Ручной smoke-сценарий — выполняется на реальной странице после установки v9.16.

1. Откройте **https://www.ozon.ru/my/orderlist/**.
2. Нажмите **🔬 Диагностика**.
3. В новом отчёте проверьте:
   - `JSON.pickupPoint` / `JSON.paymentStatus` для доставленных заказов = **🟡 N/A** (при успешном `detailsAddress`), **не** `❌ FAIL`;
   - `JSON.fallbackAmount` заполнен (из товаров, с копейками);
   - `JSON.cardDeliveryDate` заполнен (из `statusText`/shipmentWidgets) — у доставленных = дата получения (**✅ OK**);
   - `detailsAddress` = **OK**;
   - заказ «В пути» с `badgeStatus="Оплачен"` → `product (final) pay="✅ Оплачен"`.

## 🔒 Приватность

Диагностические отчёты из папки `diagn/` содержат **персональные данные** (номера заказов, адреса, имена) и **не хранятся в git** (папка в `.gitignore`).
