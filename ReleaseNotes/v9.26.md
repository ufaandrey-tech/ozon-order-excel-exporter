# Ozon Order Copier v9.26

## Исправления

- Исправлено ложное сопоставление плитки с чужим заказом: раньше контейнер
  ссылки (`closest('section')`) мог захватить весь список, и «совпадение по
  фото» срабатывало на первом попавшемся заказе.
- Теперь карточка определяется как ближайший предок ссылки, внутри которого
  ровно один номер заказа, и требуется совпадение минимум двух фото товаров
  (для плитки с несколькими товарами).
- Убрано сопоставление по одной дате — оно давало неверные номера.
