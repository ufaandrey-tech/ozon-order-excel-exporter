# Ozon Order Copier v9.28

## Исправления

- Поиск завершённого заказа из плитки: добавлена проверка кандидатов по дате
  через страницу заказа (`orderdetails`) со сверкой фотографий товаров.
  Если фото в карточке списка не совпали напрямую, скрипт проверяет до 4
  кандидатов и выбирает заказ, где совпало не меньше двух фото плитки.
- В диагностику добавлен `DOM.listPageInfo`: для каждой страницы списка
  пишется URL, HTTP-статус, размер HTML, количество ссылок на заказы,
  число уникальных номеров и сколько фото плитки встречается в HTML.
- Ускорен мост в страничный мир (ожидание 0,6 с, ответ 1,8 с) и добавлены
  варианты URL списка (`/my/orderlist/` и `/my/orderlist`).
