# 📋 Ozon Order Copier

Пользовательские скрипты для экспорта заказов с маркетплейса **Ozon** в Excel и буфер обмена. Помогает вести учёт покупок, отслеживать статусы доставки и оплаты, сохранять данные для бухгалтерии или личного архива.

## 👤 Для кого

- **Частные покупатели** Ozon — чтобы отслеживать свои заказы, суммы, статусы оплаты
- **Семейный/общий аккаунт** — учёт кто что заказал и на какую сумму
- **Малый бизнес и самозанятые** — быстрый экспорт заказов в Excel для бухгалтерии
- **Те, кто делает много заказов** — когда стандартного списка Ozon недостаточно

## 🚀 Что делает скрипт

После установки на странице [Мои заказы Ozon](https://www.ozon.ru/my/orderlist) появляются три кнопки:

| Кнопка | Действие |
|---|---|
| 📋 **Копировать** | Копирует все заказы в буфер обмена в табличном виде (TSV, вставляется в Excel) |
| 📊 **Excel** | Скачивает готовый `.xlsx` файл со всеми данными |
| 🔬 **Диагностика** | Собирает технический отчёт для отладки (если что-то не работает) |

**Какие данные извлекаются:**

- Номер заказа
- Статус доставки (в пути, готов к выдаче, доставлен, отменён и др.)
- Товары с названиями и количеством
- Цены товаров и общая сумма заказа
- Статус оплаты (оплачен / не оплачен / к оплате при получении / частично)
- Адрес пункта выдачи
- Дата доставки (включая диапазоны вида «17–18.07.2026»)
- Фото товаров (встраиваются в Excel)

**Особенности:**

- **JSON-first подход** — данные извлекаются напрямую из внутреннего API Ozon (`state-orderList`), не зависит от CSS-классов вёрстки. Скрипт устойчив к частым редизайнам сайта
- **Составные заказы** — корректно обрабатываются заказы с несколькими отправлениями (посылками)
- **Авто-подгрузка деталей** — для каждого заказа подгружается страница с полными данными о товарах, ценах и адресе ПВЗ
- **Retry при ошибках** — до 3 попыток с экспоненциальной задержкой при сетевых сбоях

## 📦 Установка

### 1. Установите Tampermonkey

Скрипт работает через расширение **Tampermonkey** (или аналоги: Violentmonkey, Greasemonkey):

| Браузер | Ссылка |
|---|---|
| Chrome / Edge  | [Tampermonkey в Chrome Web Store](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo) |
| Firefox | [Tampermonkey в Firefox Add-ons](https://addons.mozilla.org/firefox/addon/tampermonkey/) |

### 2. Установите скрипт

1. Откройте Tampermonkey → **Создать новый скрипт**
2. Скопируйте содержимое [`ozon-orders-copier.user.js`](ozon-orders-copier.user.js)
3. Вставьте в редактор и нажмите **Сохранить** (`Ctrl+S`)

### 3. Авторизуйтесь на Ozon

> ⚠️ **Важно:** Скрипт работает **только с вашими собственными заказами**. Необходимо быть авторизованным на [ozon.ru](https://www.ozon.ru) под своей учётной записью.

### 4. Перейдите на страницу заказов

Откройте **[https://www.ozon.ru/my/orderlist](https://www.ozon.ru/my/orderlist)** — кнопки появятся в правом нижнем углу.

## 🐍 Python-шаблон (дополнительно)

В проекте есть скрипт [`generate_template.py`](generate_template.py) — он создаёт готовый Excel-шаблон для ручного учёта заказов (с форматированием, выпадающими списками и условным форматированием).

```bash
pip install openpyxl
python generate_template.py
# Создастся файл Ozon_Заказы_шаблон.xlsx
```

## 🔒 Приватность

- Скрипт работает **полностью локально** в вашем браузере
- Никакие данные **не отправляются** на сторонние серверы
- Все запросы идут только к официальному API Ozon (`ozon.ru`, `ir.ozone.ru`, `cdn1.ozon.ru`)
- Код открыт — вы можете проверить, что он делает

## 🛠 Технический стек

- **JavaScript** (Tampermonkey UserScript)
- **ExcelJS** — библиотека для генерации `.xlsx` (подгружается с CDN)
- **Python 3 + openpyxl** — для [`generate_template.py`](generate_template.py)
